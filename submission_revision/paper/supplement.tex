\section{S2: New Executions}
\subsection{Environment and Initial Paired LR}
New runs use Python 3.12.14, scikit-learn 1.8.0, NumPy 2.3.5, SciPy 1.17.0 and pandas 2.2.3 on CPU. They are assistant-executed N evidence, not author-independent replication or Kaggle execution. Single-thread BLAS and OpenMP settings limit hidden parallelism. Historical package versions are unknown.

The initial comparison uses the notebook cleaner and signals, all four source TF-IDF branches, unchanged row order, and three shuffled stratified folds with seed 42. LR uses multinomial SAGA, $C=3$, tolerance $10^{-3}$ and 2,000 iterations. Class weights are computed once from all labels and held fixed in both arms; this isolates representation-fit scope, not every evaluation exposure. Global fitting gives 0.522060895664; training-fold fitting gives 0.518871561557. The difference is 0.003189334107. All six fits reach 2,000 iterations. Matching the rounded historical LR score does not authenticate that earlier run.

\subsection{Convergence Sensitivity}
LBFGS uses the same $C=3$ multinomial L2 objective, tolerance $10^{-6}$ and maximum 2,000 iterations. The global and fold-fitted arms retain fixed global class weights. Group-aware and exclusion arms use local class weights and fold-fitted TF-IDF. These additional arms change the split or corpus and are not paired estimates of duplication alone. The global-minus-fold difference is 0.001749622276, compared with 0.003189334107 at the SAGA cap. Optimization therefore materially changes this protocol sensitivity. Gradient diagnostics use normalized class-weighted multinomial loss plus $\|W\|_2^2/(2C\sum_i s_i)$, leaving intercepts unpenalized.

\subsection{Reduced Nested Stacking}
The base order is LR\_C3, SGD, CNB, giving nine probabilities in fixed class order $(0,1,2)$. LR keeps the source SAGA budget above. SGD uses modified Huber loss, $\alpha=10^{-4}$, 200 iterations and local class weights. CNB uses only the two character branches, $\alpha=0.05$ and \texttt{norm=True}. Both have two-fold isotonic calibration and explicit \texttt{ensemble=True}. Calibrators fit within each permitted base training subset. TF-IDF is fitted before that internal calibration split but never on outer assessment rows. Meta-LR uses $C=10$, 500 iterations and outer-training class weights. Explicit retention resolves an unknown historical default for this new run rather than retroactively assigning it to the notebook.

Each outer fold first fits bases on all outer training rows to produce assessment probabilities. These probabilities are identical in both comparison arms. Nonnested meta training uses other rows of the common outer-OOF matrix, whose base fits include the current assessment labels. Nested meta training instead rebuilds three-fold base OOF features inside the current outer training subset. There are three outer base sets and nine inner base sets, each with three candidates. Meta fitting uses only allowed training labels. This protects outer labels in the nested arm while fixing the assessment predictor across arms. The smaller inner base-training samples are part of this protocol change.

Pooled nonnested macro-F1 is \NonNested{}; nested macro-F1 is \Nested{}; the signed nonnested-minus-nested difference is \StackDifference. No LightGBM, threshold tuning, squared-F1 weights or final candidate selection enters this contrast. It therefore does not quantify the optimism of the complete historical weighted ensemble. All 12 LR fits reach the 2,000-iteration cap. Nested Meta-LR stops at 43, 43 and 40 iterations (outer folds 1, 2 and 3). Iteration records and all inner meta-training probabilities are retained.

\subsection{Conditional Paired Bootstrap}
We rescore fixed paired OOF predictions, never retraining inside this bootstrap. For row resampling, the $(y,\hat y_A,\hat y_B)$ triplets define 27 cells. For each true class, multinomial sampling of its nine empirical triplet frequencies is equivalent to resampling paired rows within that class. We use 5,000 replicates and seed 42. Each replicate produces both confusion matrices and their macro-F1 difference. The percentile 95\% interval is \RowCI.

For cluster resampling, the unit is a unique exact raw string. Sample the same number of groups with replacement and carry every group row together, preserving label conflicts; replicate row counts can change. We use 2,000 replicates with seed 42. The percentile interval is \ClusterCI. Both intervals condition on the already fitted predictions. They omit training variability and do not establish independent user/thread sampling or a universal cross-validation variance estimate. A positive conditional interval is not a claim that global preprocessing improves out-of-sample generalization.
